# 시연 점검 체크리스트

Wi-Fi CSI 기반 낙상 감지 시스템의 시연 준비와 동작 확인을 위한 점검 양식입니다.

이 문서는 시험 결과가 아닌 체크리스트입니다.
각 항목은 실제로 확인한 후 체크하고, 발견한 문제는 하단에 기록합니다.

## 1. 시연 준비

- [ ] Jetson과 센서 노드의 전원 연결을 확인한다.
- [ ] 네트워크 연결과 데이터 수신 설정을 확인한다.
- [ ] 사용할 모델과 설정 파일의 경로를 확인한다.
- [ ] 센서 노드에서 CSI 데이터가 수신되는지 확인한다.
- [ ] 실시간 추론 프로그램이 실행되는지 확인한다.
- [ ] 상태 API가 실행되는지 확인한다.
- [ ] 앱에서 현재 상태를 조회할 수 있는지 확인한다.

## 2. 일반 동작 확인

- [ ] 빈방 상태에서 출력 결과를 확인한다.
- [ ] 서 있는 상태에서 출력 결과를 확인한다.
- [ ] 걷는 동작에서 출력 결과를 확인한다.
- [ ] 앉는 동작에서 출력 결과를 확인한다.
- [ ] 일반적으로 눕는 동작에서 낙상 오탐 여부를 확인한다.
- [ ] 허리를 숙이거나 물건을 줍는 동작에서 낙상 오탐 여부를 확인한다.

## 3. 낙상 시나리오 확인

- [ ] 매트와 보조자 등 안전 조치를 마련한다.
- [ ] 안전하게 준비한 낙상 시연에서 알람 발생 여부를 확인한다.
- [ ] 낙상 후 누운 상태에서 판정 변화를 확인한다.
- [ ] 알람 발생 후 앱에 표시되는 내용을 확인한다.
- [ ] 다시 일어선 뒤 상태 변화를 확인한다.

## 4. 연결 장애 확인

- [ ] 센서 노드 하나의 연결이 끊겼을 때 표시를 확인한다.
- [ ] 전체 데이터 수신이 끊겼을 때 표시를 확인한다.
- [ ] 연결 복구 후 데이터 수신이 재개되는지 확인한다.
- [ ] 연결 복구 후 실시간 추론이 재개되는지 확인한다.

## 주의사항

- 실제로 확인하지 않은 항목은 체크하지 않는다.
- 낙상 시연은 안전 조치를 마련한 뒤 진행한다.
- 비밀번호, API 키, 참여자의 개인정보는 기록하지 않는다.
- 이 체크리스트의 완료만으로 감지 정확도나 안전성이 검증되는 것은 아니다.
